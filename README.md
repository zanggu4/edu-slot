# 슬롯머신 배우기 — 5릴 교육용 슬롯

카지노 슬롯머신을 처음 접하는 사람이 **직접 돌려보면서 규칙을 익히는** 웹앱입니다.
가상 크레딧만 사용합니다. 매 판 "왜 당첨인지 / 왜 아닌지"를 전부 펼쳐서 설명하는 것이 핵심 기능입니다.

## 실행

```bash
pnpm install      # npm install
pnpm dev          # npm run dev      → http://localhost:5173
pnpm test         # npm test         → vitest (엔진 단위 테스트)
pnpm sim          # npm run sim      → 100만 판 RTP 시뮬레이션
pnpm build        # npm run build    → dist/ (정적 파일)
pnpm preview      # npm run preview
```

### 도커

```bash
docker compose up --build   # → http://localhost:8080
```

멀티스테이지 빌드(node → nginx). 최종 이미지는 nginx + `dist/` 정적 파일만 담습니다.

## 구조

```
src/engine/        순수 함수 판정 엔진 (React 의존 없음)
  types.ts         공용 타입
  symbols.ts       심볼 정의, 배당표
  rng.ts           mulberry32 (시드 주입 가능)
  reels.ts         릴 스트립, 가중치, 스핀 결과 생성
  paylines.ts      25개 라인 좌표
  evaluateLines.ts 페이라인 판정 → LineResult[]
  evaluateWays.ts  243 웨이즈 판정 → WayResult[]
  scatter.ts       스캐터 판정, 프리스핀 트리거
  evaluate.ts      위 셋을 묶은 한 판 판정
  explain.ts       판정 결과 → 한국어 설명 데이터. UI는 이 출력을 렌더만 한다
  simulate.ts      RTP 시뮬레이터 (pnpm sim)
src/store/         zustand 게임 상태
src/components/    기계 영역(machine) / 설명 영역(explain) / 모달
src/assets/symbols SVG 심볼

```

## 기계 설정 (프로필)

화면 상단 탭 오른쪽에서 두 설정을 전환할 수 있습니다. 기본값은 **실제형**입니다.

| 프로필 | 목표 환수율 | 프리스핀 진입 | 참고 |
|---|---|---|---|
| **실제형** (기본) | 약 90% | 약 1/150판 | 지상 카지노 슬롯의 일반적인 수준. 릴당 스캐터 1개, 스트립 32칸 |
| 교육용 | 약 94% | 약 1/40판 | 규칙을 빨리 보기 위해 이벤트를 자주 나오게 조정 |

실제 카지노 슬롯의 환수율은 지역·데노미에 따라 대략 85~96% 범위이고(지상 카지노 88~92%, 온라인 95~96%가 흔함),
보너스 진입은 100~200판에 1번이 보통입니다. 실제형은 그 중간값인 90% / 1/150을 목표로 잡았습니다.
배당표는 두 설정이 같고 릴 스트립(심볼 가중치)만 다릅니다.

## 시뮬레이션 결과 (100만 판, seed 20260914)

`pnpm sim` 출력. 페이라인은 25줄 × 라인당 1(총 25), 웨이즈는 총 베팅 25 기준. 프리스핀 포함.
`pnpm sim --profile real|edu --mode lines|ways --seed N --spins N` 으로 조건을 바꿀 수 있습니다.

### 실제형 (기본)

| 항목 | 페이라인 모드 | 웨이즈 모드 |
|---|---|---|
| RTP 전체 | **90.75%** | **90.98%** |
| 히트 빈도 (당첨 > 0인 판) | 52.6% | 43.7% |
| 프리스핀 진입 | 1 / 148.7 판 | 1 / 131.6 판 |
| 프리스핀 세션당 평균 획득 | 총 베팅의 약 21.7배 | 총 베팅의 약 25.2배 |

시드를 바꿔도(1, 2) 페이라인 90.4~90.8%, 웨이즈 89.8~91.0% 범위입니다.
히트 빈도가 50% 안팎인 것은 체리 2개 지급 때문이며, 실제 25라인 비디오 슬롯도 소액 당첨이 많아 40~55%대가 보통입니다.
그 소액 당첨 대부분이 "이겼는데 잃은" 판입니다.

### 교육용

| 항목 | 페이라인 모드 | 웨이즈 모드 |
|---|---|---|
| RTP 전체 | **93.33%** | **94.64%** |
| ├ 라인/웨이 (일반 스핀) | 47.4% | 43.4% |
| ├ 스캐터 (일반 스핀) | 6.8% | 7.6% |
| └ 프리스핀 기여 | 39.1% | 43.7% |
| 히트 빈도 (당첨 > 0인 판) | 72.5% | 38.5% |
| 프리스핀 진입 | 1 / 40.1 판 | 1 / 37.1 판 |
| 스캐터 3개 이상 | 1 / 40.6 판 | 1 / 37.1 판 |
| 프리스핀 세션당 평균 획득 | 총 베팅의 약 15.7배 | 총 베팅의 약 17배 |

시드를 바꿔도(1, 2, 11) 페이라인 93.5~93.9%, 웨이즈 94.0~95.5% 범위입니다.

### 왜 웨이즈 릴이 따로 있는가

두 모드는 같은 배당표를 씁니다. 그런데 243웨이 판정은 k개 일치 확률이 페이라인 한 줄의 약 3^k 배라서,
페이라인용 릴을 그대로 쓰면 웨이즈 환수율이 200%를 넘습니다.
그래서 웨이즈 모드는 릴마다 주력 심볼을 엇갈리게 둔 별도 스트립을 씁니다.
실제 243웨이 기계는 배당표 자체를 훨씬 낮게 잡습니다. 모드 탭을 바꾸면 **직전 릴 결과는 그대로 두고 판정만 다시** 합니다.

## 규칙 요약

- 5릴 × 3행. 릴마다 가중치 스트립이 다릅니다. 와일드(⭐)는 릴 2, 3, 4에만.
- 페이라인: 25줄. 왼쪽 릴부터 같은 심볼 3개 이상. 중간에 끊기면 그 앞까지만. 한 줄에서 최고 배당 하나만.
- 웨이즈: 릴1부터 인접 릴에 같은 심볼이 있으면 이어짐. 웨이 수 = 릴별 개수의 곱. 웨이당 베팅 = 총 베팅 / 25.
- 체리만 2개도 1 지급. 스캐터(🎁)는 위치 무관, 3개 이상이면 프리스핀 10회(재발동 +5), 모든 당첨 ×2, 배당은 총 베팅 기준.
- 시작 잔액 1,000. 데노미(10원/100원/1,000원)는 표시 전용.
- 기계 설정(실제형/교육용)은 스핀 중이나 프리스핀 중에는 바꿀 수 없고, 브라우저에 기억됩니다.
